### *Zero-UI Agentic HR on Kolay İK*

## 1. The "Why" — Disruption Thesis

> Traditional HRIS vendors sell **databases with forms**. Their "AI" features are retrofits — glorified search bars and GPT wrappers bolted onto decade-old CRUD UIs. The structural problem: the UI *is* the product, so they can never kill it.

**Our thesis is simple:** The best HR software is the one nobody has to open.

| Dimension | Legacy HRIS | Atmon HR (Agentic Layer) |
|---|---|---|
| **Interface** | 200+ screen menus | Natural language + zero-UI triggers |
| **Data flow** | Manager → form → approval → HR → form | Agent orchestrates end-to-end |
| **Intelligence** | Dashboards you have to read | Anomalies pushed to you when they matter |
| **Cost to add features** | 3-sprint dev cycle, QA, rollout | `@mcp.tool` + `@mcp.prompt` = days |
| **Integration** | API connectors sold separately | MCP is the universal connector by design |

**Why wrapping an API in an MCP Agent disrupts the market:**

1. **Speed-to-value asymmetry.** Kolay İK spent years building the CRUD layer. We inherit it instantly via their API and compete on the *intelligence* layer, which they cannot ship without rebuilding their frontend.
2. **Model-agnostic distribution.** MCP is supported by Claude, Gemini CLI, Cursor, Windsurf, and soon ChatGPT. We don't need users to download an app — we meet them inside *their* existing AI tool.
3. **Compound data advantage.** Every interaction enriches our understanding of company norms. After 6 months, we know patterns (leave cadence, turnover by department, promotion velocity) that no static dashboard can surface.
4. **Seller becomes platform.** We don't replace Kolay İK; we make it *more* valuable. This is a wedge, not a competitor — until it is.

### Phase 3: The Autonomous "Agentforce" HR (6–12 Months)

**Theme:** *"The agent starts the conversation."*

This is the Salesforce Agentforce paradigm: the system doesn't wait for a prompt. It monitors API state, detects anomalies, and *proactively initiates* action. This requires a background scheduler polling Kolay İK data.

| # | Feature | Trigger Condition | Autonomous Action | Human-in-the-Loop |
|---|---|---|---|---|
| 3.1 | **Expense Fraud Detector** | Transaction amounts > 2σ from employee's historical mean, or duplicate amounts within 48h | Flag + freeze for review + draft investigation summary | Manager approval to release/reject |
| 3.2 | **Proactive Compensation Adjustment** | Tenure milestone (1yr, 3yr, 5yr) + no salary change in 12+ months + peer benchmark | Draft comp adjustment proposal with market data | HR Director approval to execute |
| 3.3 | **Attrition Early Warning System** | Composite score from: declining leave usage, no training in 6mo, peer departures from same dept | Push alert to manager + suggested retention actions (bonus, training, 1:1) | Manager chooses action |
| 3.4 | **Automated Probation Review Trigger** | 85 days since `employment_start` + no recorded review event | Create calendar event for review + prepare employee snapshot + notify manager | Manager confirms or reschedules |
| 3.5 | **Overtime Compliance Guardian** | Weekly timelog hours > legal threshold (45h in Turkey) for 2+ consecutive weeks | Alert HR + draft warning notification + create compliance log | HR confirms send |
| 3.6 | **Ghost Employee Auditor** | No leave, timelog, training, or transaction activity for 60+ days on active employee | Generate audit report + flag for HR review | HR confirms status or triggers investigation |
| 3.7 | **Succession Pipeline Builder** | Senior role termination/retirement detected → scan org for candidates with matching training portfolio + tenure | Draft succession shortlist with rationale | HR Director reviews candidates |

**Phase 3 Architecture Requirements:**

```
┌────────────────────┐
│  Scheduler / Cron  │ ← Runs every N hours
│  (Background Job)  │
└────────┬───────────┘
         │ Calls service layer
         ▼
┌────────────────────┐
│  Anomaly Detection │ ← Statistical analysis on fresh data
│  Engine            │
└────────┬───────────┘
         │ Anomaly found?
         ▼
┌────────────────────┐
│  MCP Prompt        │ ← @mcp.prompt for HITL approval
│  (Notification)    │
└────────┬───────────┘
         │ Approved?
         ▼
┌────────────────────┐
│  MCP Tool          │ ← @mcp.tool executes write action
│  (Execution)       │
└────────────────────┘
```

**Phase 3 Outcome:** The HR team's morning starts with an AI-curated briefing: "3 probation reviews due this week, 1 overtime compliance alert, and a compensation adjustment proposal for your top performer in Sales." Zero screens opened.

def flight_risk_analysis(department: str | None = None) -> dict:

    - No bonus/premium transaction in 12 months      → +15 risk points  
    - Title unchanged for 24+ months                 → +20 risk points
    - Department has had 2+ exits in last quarter     → +15 risk points
    - No training assigned/completed in 12 months     → +15 risk points
    """
    # Implementation:
    # 1. person_list(status="active") → all employees
    # 2. For each: person_view → tenure, title, hire date
    # 3. leave_list(person_id=X, last 6 months) → leave frequency
    # 4. transaction_list(person_id=X, type="bonus") → bonus cadence

## 4. The Moat — Why We Win

### Against Kolay İK releasing native AI

| Their constraint | Our advantage |
|---|---|
| Tied to their own UI. Every AI feature must render inside their web app. | We are **UI-agnostic**. The agent runs inside Claude, Gemini, ChatGPT, Slack — wherever the user already is. |
| Ship on their release cycle (quarterly). | We ship `@mcp.tool` wrappers in **days**. |
| Their AI has access to **one tenant's data** in isolation. | We can fuse Kolay İK with **any other MCP server** — finance, project management, CRM — creating cross-domain intelligence they can never match. |
| They need to maintain backwards compat with existing UI. | We are greenfield. No legacy screens to protect. |

### Against Microsoft Copilot / generic AI assistants

| Their constraint | Our advantage |
|---|---|
| Horizontal. Copilot is a "jack of all trades" — it can summarize emails and draft docs but has **zero HR domain knowledge**. | We are a **vertical specialist**. We know Turkish labor law (45h/week limits, SGK reason codes), leave types, and approval workflows. |
