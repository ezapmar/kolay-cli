## 1. Technical Debt Found

### 1.1 `mcp_server.py` was a monolith -- FIXED

The monolith was split into 12 sub-modules under `src/kolay_cli/mcp/`:
`tools_people.py`, `tools_leaves.py`, `tools_time.py`, `tools_training.py`, `tools_finance.py`, `tools_org.py`, `tools_analytics.py`, `tools_wellness.py`, `tools_misc.py`, `tools_session.py`, `prompts.py`, `__init__.py`.

`mcp_server.py` is now 287 lines (core setup, middleware stack, resources only).

### 1.2 Duplicated `_sync_progress` boilerplate -- FIXED

Extracted to `mcp_progress.py` with a shared `sync_progress_bridge(ctx)` factory. All 5 analytics tools import from there.

### 1.3 Triple token injection path -- FIXED

- `request_token` ContextVar: **removed** (grep: 0 hits)
- `os.environ["KOLAY_API_TOKEN"]` mutation: **removed** (grep: 0 hits for writeback)
- `_token_cache` / `_SENTINEL`: **removed** (grep: 0 hits)
- Token flow is now: `KOLAY_TOKEN_CTX` (set by middleware) -> `KOLAY_API_TOKEN` env (read-only) -> keyring -> config file

### 1.4 Sentinel cache -- FIXED

Dead code removed. See 1.3 above.

### 1.5 `app.py` references undefined `_log()` -- FIXED

`app.py` now uses `print(..., flush=True)` directly. No `_log` import needed.

### 1.6 Redundant `__import__` calls in `commands/mcp.py` -- OPEN

Still present on 2 lines:
- Line 11: `_home = __import__("pathlib").Path.home()`
- Line 98: `__import__("os").environ.get("MCP_API_KEY")`

Low severity, cosmetic.

### 1.7 Inline `import json` in resource functions -- OPEN

3 occurrences remain in `mcp_server.py` (lines 141, 151, 167) inside resource functions (`reason_codes`, `turkish_holidays`). Low severity.

### 1.8 `filter` shadows built-in -- PARTIALLY FIXED

Only 1 remaining occurrence in `tools_org.py` line 80. Previously was in multiple tools.

## 4. Security Notes (Updated)

Things **already done well**:
- `@require_auth` decorator with structured error responses
- `@requires_permission` decorator with JWT claim-based permission checking
- Rate limiter is opt-in, per-token, sliding-window -- solid design
- Activity log redacts long strings and never logs response payloads
- HMAC-SHA256 execution receipts for verifiable audit trails
- JWT validation has clock-skew leeway and optional signature verification
- Gatekeeper is a bonus layer, not a hard gate -- correct for MCP
- `Cache-Control: no-store` is set on 401 responses in `_send_json`

**New security layers added (2026-03-23):**
- PII Masking middleware (opt-in) -- deterministic HMAC pseudonymization of names, emails, IDs
- Payload Padding middleware (opt-in) -- uniform response sizes defeat traffic analysis
- Config Encryption at rest (opt-in) -- Fernet + PBKDF2 machine-derived key
- mTLS sidecar config (infra) -- NGINX reverse proxy with client cert verification

Things **tightened during this review run**:
- ~~`os.environ["KOLAY_API_TOKEN"]` mutation~~ FIXED
- ~~`Cache-Control: no-store` on 401 responses~~ FIXED (was missing from `APIKeyMiddleware._send_401` in `mcp_server.py`; already present in `server_middleware.py`)
- ~~Commented-out JWKS block~~ REMOVED
- ~~`_GLOBAL_LOOKUP` thread-safety bug in `pii_masker.py`~~ FIXED -- replaced with per-call local dict
- ~~Content replacement gap in `PIIMaskingMiddleware`~~ FIXED -- static-only masking now correctly updates response

Remaining:
- `__import__` usage in `commands/mcp.py` is unconventional but not a security issue

## 6. Verdict (Updated)

**Previous verdict (2026-03-20):** Token injection path and monolith file were the two biggest pain points.

**Current state (2026-03-23):** Both are fully resolved. The codebase has gone from 653 to **686 passing tests**. All P0 and P1 items from the original review are done. Only cosmetic P2/P3 items remain (inline imports, one `filter` shadow, `@filterable` decorator).

The security posture has significantly improved with four new opt-in layers (PII masking, payload padding, config encryption, mTLS infra). The middleware stack is now 9 layers deep with clear separation of concerns.

**Bottom line:** The codebase is production-ready. Remaining tech debt is cosmetic polish.

## 7. Bugs Found & Fixed During This Review Run

| File | Bug | Severity | Fix |
|---|---|---|---|
| `pii_masker.py` | `_GLOBAL_LOOKUP` was a module-level mutable dict shared across concurrent async requests -- lookups from one request could bleed into another | High | Replaced with per-call `lookup: dict` passed through `mask_value()` and `mask_dict()` |
| `pii_masker.py` | When only static fields were masked (e.g., `nationalId`), `_GLOBAL_LOOKUP` stayed empty so `masked_something` was `False` and the original unmasked content was returned | High | Removed the `masked_something` guard -- content is always replaced after processing |
| `mcp_server.py` | `APIKeyMiddleware._send_401` was missing `Cache-Control: no-store` header (the `server_middleware.py` version had it, this older duplicate did not) | Low | Added `[b"cache-control", b"no-store"]` to response headers |
